# Billboard Pro — WordPress theme for LED billboard & outdoor advertising companies

**Download:** [`billboard-pro.zip`](billboard-pro.zip) → WordPress Admin → Appearance → Themes → Add New → Upload Theme → Activate.
Then open **Appearance → Billboard Pro Setup → Import content**.

## What you get
- Premium dark/bright LED-first design (CSS-variable brand system, Customizer colours, mobile-first, no page builder).
- **Billboards** inventory with every field from the brief, **real AJAX filtering** (city, state, type, digital/static, size, availability, budget, traffic, keyword, sort) that also works without JavaScript.
- **Locations**, **Case Studies**, **Testimonials** post types; billboard detail pages with gallery/lightbox, specs, audience, map, inquiry form and related billboards.
- **Quote & contact forms** with validation, honeypot + time-trap + rate limiting, nonce, email notifications/auto-reply, and an **Inquiries inbox** (lead status, notes, CSV export).
- **SEO**: meta, Open Graph, JSON-LD (Organization, LocalBusiness, Product/Offer, Place, Article, FAQPage, Breadcrumbs), sitemap, robots.txt, `/llms.txt`, TOC, one H1 per page.
- **One-click content import** (batched — safe on shared hosting): 10 core pages incl. an LED Billboard Screens pillar page, FAQ and 40-term glossary; 23 in-depth guides; 50 real US market pages; 8 billboard types; menus; sample case studies/testimonials; sample inventory (default 20 per market = 1,000 billboards → ~1,150+ indexable URLs), all cross-linked.
- Original, royalty-free artwork bundled (no attribution needed).

> Sample billboards, prices, impressions, case studies and testimonials are placeholders — replace them with real data before launch (or remove them in one click).
